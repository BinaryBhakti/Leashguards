# Demo Scenarios

## Scenario 1: Employment Agreement

Goal: Show restrictive employment risk.

Flow:

1. Load the employment sample.
2. Select `Employment`, `Employee`, and a jurisdiction.
3. Run review.
4. Show non-compete, IP assignment, arbitration, and termination risks.
5. Open AI Review and explain jurisdiction notes.
6. Export PDF.

Key talking point:

Leashguards explains how clauses affect job mobility, ownership, and dispute rights.

## Scenario 2: Subscription Contract

Goal: Show hidden financial and renewal risk.

Flow:

1. Load the subscription sample.
2. Run review.
3. Show automatic renewal, non-refundable fees, unilateral changes, warranty disclaimers, and indemnity.
4. Open benchmark tab and show renewal notice gaps.
5. Download report.

Key talking point:

Leashguards identifies real-world consequences beyond a normal summary.

## Scenario 3: Uploaded Scanned Document

Goal: Show OCR-assisted intake.

Flow:

1. Upload a clear image scan of a contract page.
2. Confirm extracted text appears in the document box.
3. Run review.
4. Discuss OCR confidence and manual verification.

Key talking point:

Leashguards can process scanned image documents and warns users when OCR confidence is low.

## Scenario 4: Version Comparison

Goal: Show negotiation workflow.

Flow:

1. Analyze a risky contract as `v1`.
2. Edit text to add safeguards or remove risky language.
3. Change version label to `v2`.
4. Analyze again.
5. Open History and compare latest versions.

Key talking point:

Leashguards supports iterative contract negotiation and shows whether risk improved.
